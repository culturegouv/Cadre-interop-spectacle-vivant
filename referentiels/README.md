# Référentiels et vocabulaires contrôlés

Un référentiel est un jeu de données partagé et stable dans le temps, servant de
référence commune. La récurrence de ces données dans les systèmes leur confère
une valeur particulière, notamment pour l'aide à la décision, et leur partage
évite les doublons, les contradictions et les incomplétudes.

Aucun référentiel n'est spécifié à ce stade. Ils font l'objet du cycle de
travail suivant.

l'usage courant et une version en données liées pour l'exploitation automatisée.

## Conditions pour qu'un référentiel existe

Un jeu de données ne devient un référentiel que s'il réunit cinq conditions. Un
identifiant stable et pérenne, une licence autorisant la réutilisation et la
redistribution, un détenteur identifié et joignable, une granularité compatible
avec l'objet décrit, et une politique de mise à jour connue.

Sans ces cinq éléments, une source est au mieux une amorce.
