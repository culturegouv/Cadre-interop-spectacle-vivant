# Exemples

Les exemples de ce dossier sont valides et passent la validation automatique.
Ils sont vérifiés à chaque proposition de modification du dépôt.

Le sous-dossier `invalides/` contient des exemples volontairement incorrects.

Les exemples référencent le contexte public de schema.org, qui est ce que lisent
les moteurs de recherche. La validation hors ligne substitue un contexte local,
sans modifier les fichiers.
